# Opportunities

Two things live here:

- **`inbox.md`** — triage of inbound opportunity flow. Everything gets a verdict,
  and the verdict is dated.
- **`research/`** — proactive prospecting: funders and calls ACBN would qualify
  for but hasn't found yet.

An opportunity graduates to `grants/applications/` with `stage: prospect` the
moment there's a real intent to apply. Until then it stays here, so the pipeline
never fills with things nobody decided on.

## Screening questions

In order. The first four are disqualifiers — check them before reading the
guidelines properly, because each one voids an otherwise strong application.

1. **Eligible entity?** Nonprofit / charity / for-profit — and which of Ryan's
   entities is the applicant?
2. **Eligible geography?** Peel, Ontario, national, Atlantic, BC?
3. **Deadline realistic?** Under three weeks for a major federal application is
   usually a no unless most of it is reusable.
4. **Charitable status required?** Recurring blocker — resolve once in
   `orgs/acbn.md`.
5. **Real mandate fit**, or would we be bending the program to fit us? Bent
   applications cost the same as fitted ones and lose.
6. **Ask size vs. effort.** A $10,000 grant with a 40-page application is a bad
   trade unless it opens a relationship worth more than the money.
7. **Does it strengthen a relationship** we want long-term?

## Verdicts

`pursue` · `watch` (right funder, wrong cycle) · `pass` (with the reason — a
recorded reason stops us re-litigating the same call next year) · `client`
(better fit for an org ACBN writes for)
