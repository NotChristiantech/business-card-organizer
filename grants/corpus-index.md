`partial` (record exists, folder not yet read) · `todo` · `skip` (not a grant).

## How to ingest a folder

1. List its contents; read the application narrative, the budget, and any
   decision or reporting correspondence.
2. Create or update the record in `applications/`, and the dossier in `funders/`.
3. Pull any reusable answer into `library/answers/` — **this is the point of the
   exercise**, not the record itself.
4. Record the outcome and, if declined, the reason.
5. Set this row's status to `done`.
