# Answer bank

Reusable narrative blocks. Each file answers a *type* of question rather than one
funder's specific wording, so it can be adapted rather than rewritten.

## Front-matter

```yaml
question_types: [mission, mandate]   # phrasings this block answers
applicant: acbn                      # or a client org id, or `any`
status: ready                        # ready | draft | needs-data
```

## How to use

1. Read the funder's question and find the block whose `question_types` matches.
2. Adapt: match the funder's vocabulary, hit their word count, foreground the
   pillar they fund.
3. Never paste unchanged. A reviewer who has seen ACBN before will notice, and
   an answer that ignores the specific question scores badly regardless of
   quality.

## How to improve

After a decision lands, come back. If a funder quoted our language approvingly,
or scored a section low, record it in the block's Notes. This is the mechanism
that makes the library get better instead of just getting bigger — an answer
bank nobody revises is just old text.

## Status meanings

- `ready` — has been used successfully, evidence is verified
- `draft` — structurally sound, not yet battle-tested
- `needs-data` — the frame is right but the supporting numbers don't exist yet
